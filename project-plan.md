# Saurabh.AICreates — Project Plan

The goal is a **complete premium digital invitation package**, not only a basic website.

## Template 01 — Royal Wedding Website
- Mobile-first scrolling invitation website
- Opening envelope animation before the invitation is revealed
- Couple names and wedding date
- Countdown timer
- Couple story and photo gallery
- Event schedule cards
- Venue address and map link
- RSVP form with validation and a clear success state
- Elegant motion, reduced-motion support, and matching royal styling

## Template 02 — Matching Cinematic Video
- Vertical 9:16 deliverable for Reels, WhatsApp and Stories
- Same burgundy, antique-gold, ivory and floral visual identity
- Scene-by-scene storyboard and AI video prompts
- Transitions, on-screen typography, duration and sound/music notes
- No voiceover unless the customer specifically requests it
- Export checklist for a final MP4

Note: prompts and production guidance are source assets; a final rendered MP4 must be generated and reviewed separately.

## Template 03 — Matching Image Card
- WhatsApp-ready invitation card
- Same palette, fonts, border ornaments and wording as the website/video
- Editable text layout and image-generation/background prompt
- Export guidance for high-resolution PNG/JPG
- Check spelling, date, venue, text contrast and safe margins

## Template 04 — Reusable Customer Setup
- One customer data file for names, dates, photos, events, venue and RSVP details
- Shared style tokens so website, video and card stay visually consistent
- Customer checklist and pre-delivery QA
- Fictional demo content must be replaced before customer delivery

## Build order
1. Finish and test the Royal Wedding Website.
2. Add the opening-envelope experience and complete sections.
3. Build the matching image-card template.
4. Write the cinematic video storyboard and prompts.
5. Connect customer data/configuration across the templates.
6. Test mobile layout, links, spelling, date/time and customer-specific details.
