# Saurabh.AICreates — Project Plan

The goal is a reusable premium digital-invitation portfolio: each template can include a website/card design, scene-wise image assets, and a final cinematic video.

## Template portfolio (10 themes)

1. **Royal Burgundy & Gold** — burgundy, antique gold and ivory; current first template.
2. **Ivory & Champagne Gold** — elegant ivory with champagne-gold details.
3. **Emerald Green Royal** — emerald green and antique gold.
4. **Blush Pink Floral** — blush pink, ivory and romantic roses.
5. **Midnight Blue Luxury** — midnight blue and gold.
6. **Rajasthani Heritage** — traditional Rajasthani architecture, motifs and festive colours.
7. **Black & Gold Modern** — bold, minimal black-and-gold luxury.
8. **Lavender Dream** — lavender, lilac and silver.
9. **Sunset Marigold** — marigold, sunset orange and terracotta.
10. **Destination Wedding** — cinematic beach, palace or resort destination style.

## Repository strategy

Keep all ten templates in this single repository; do not create a separate repository per theme. Use one clearly named folder per template, with subfolders as needed:
- `images/` — individual scene images and approved visual assets
- `video/` — final rendered MP4 (add only after reviewing the file)
- `card/` — static invitation card assets
- `README.md` — theme description, asset list and production notes

Use consistent, descriptive filenames. Do not commit generated storyboard sheets in place of required individual scene images. Binary image/video assets need to be uploaded using GitHub's web interface or Git/Git LFS as appropriate; text-file connector actions alone do not upload binary media.

2. Upload the approved Template 01 assets to this repository.
3. Finish the matching static invitation card and reusable customer setup.
4. Start Template 02 only after Template 01 is organised.
5. Repeat the same production workflow for Templates 03–10.
6. Connect the portfolio assets to the separate website repository later.

## Quality checks

- Keep a consistent visual identity within each template.
- Check spelling, names, date, venue, text contrast and safe margins.
- Review mobile/vertical framing before delivery.
- Confirm rights/licensing for all audio and third-party assets.
- Replace fictional demo details before customer delivery.
