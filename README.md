# Saurabh.AICreates — Digital Invitations

Reusable digital invitation templates by **Saurabh.AICreates**.

## First template: Royal Wedding

A responsive burgundy-and-antique-gold wedding invitation demo featuring:
- Couple names and invitation introduction
- Live countdown to the wedding date
- Wedding event and venue details
- Google Maps search link
- Mobile-friendly layout

## Preview locally

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## Customize the demo

- `index.html` — names, date, event time, venue and invitation copy
- `assets/css/styles.css` — colors, typography and layout
- `assets/js/main.js` — countdown target date

The current names and event details are fictional demo content. Replace them before delivering an invitation to a customer.
